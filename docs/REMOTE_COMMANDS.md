# PC 원격 명령 — 설계안

> 상태: **승인 (2026-11-20) · 구현 v0.54.0(M-69)**.
> 결정(사용자): 첫 버전에 잠그기·화면 끄기·미디어·볼륨·다시 시작·절전·사용자 정의 명령·깨우기 **모두**. 시스템 명령은 확인 + 휴대폰 잠금 해제. **잠그기·화면 끄기·미디어는 기본 켬**(다시 시작·절전은 기본 꺼짐). **다른 PC에서는 요청하지 않음(휴대폰만)** — §4.5는 하지 않는다. 사용자 정의 명령도 `confirm`(확인 + 잠금 해제)이다.
> 바탕: 프로젝트 원칙 `00_project_overview.md` §4.2(임의 셸 명령 원격 실행 제외), `01_architecture.md` §7(원격 재부팅·종료는 별도 기능 스위치), `09_config_security.md` §6(위험 기능의 조건), `15_risks_and_limits.md` §6. 경로·키는 M-15~M-18(경로), M-47(기기 그룹), M-62(기기·PC 쌍 합의 키)를 그대로 쓴다.

## 1. 요구와 성공 기준

**요구(사용자)**: 휴대폰이나 다른 PC에서, 그 PC가 허용한 명령을 요청한다. KDE Connect의 "명령 실행"처럼 재부팅·잠그기 정도. 더 넣을 만한 명령이 있는지도 본다. 전원 끄기는 연결이 끊겨 불편하니 뺀다.

**성공 기준**
- 휴대폰의 PC 화면에서 [잠그기]·[다시 시작] 같은 버튼을 누르면 그 PC에서 실행되고, 결과가 휴대폰에 뜬다. 다른 PC의 Homebase 창에서도 같다.
- 명령마다 PC에서 사용자가 켠 것만 보인다(기본은 모두 꺼짐).
- 다시 시작처럼 되돌릴 수 없는 명령은 PC에 카운트다운과 [취소]가 뜨고, 다시 켜지면 휴대폰에 알린다.
- 토큰이 새어도, Cloudflare 엣지가 요청을 봐도, 명령을 위조하거나 다시 보내지 못한다.
- 누가 언제 무엇을 했는지 PC 알림 센터에 남는다.

## 2. 지금 구조에서 확인한 것

| 무엇 | 지금 | 영향 |
|---|---|---|
| 프로젝트 원칙 | 임의 셸 원격 실행은 범위 밖이다. 위험 기능은 설정에서 명시적으로 켜기, 명령별 허용 목록, 확인 토큰, 감사 기록, 시간 제한을 모두 갖춰야 한다(`09_config_security.md` §6) | 고정된 명령 목록만 둔다. 명령마다 PC에서 켜고, 요청은 봉인하고 한 번만 쓰며, 기록한다 |
| 명령 모델 | `RemoteCommand`(요청자 종류 `PairedDevice`, 신뢰 수준, 위험 수준 `ReadOnly`·`UserSessionMutation`·`SystemMutation`·`Destructive`)와 `IRemoteCommandRouter`가 있다. 아직 연결하지 않았다(`LegacyRemoteCommandRouter`) | 이 모델을 쓴다. 명령마다 위험 수준을 매긴다 |
| 실행 위치 | Agent는 LocalSystem(세션 0)이라 사용자 화면에 닿지 못한다. 트레이는 사용자 세션에 있다(브리지 파이프) | 잠그기·화면 끄기·미디어는 **트레이**가, 다시 시작·절전은 **Agent**가 실행한다 |
| 요청 경로 | 휴대폰 → PC 요청은 Bearer 토큰으로 인증한다. Cloudflare 경로는 엣지에서 TLS가 풀려 토큰이 보인다 | 명령 본문을 기기·PC 합의 키(M-62)로 봉인해 엣지가 만들거나 다시 보내지 못하게 한다(클립보드와 같은 방식) |
| PC → PC | Agent가 상대 PC에 기기로서 요청하는 길이 있다(`HubLinkService`, 클립보드·파일에서 씀) | 같은 길을 쓴다 |
| 재부팅 뒤 | 서비스가 자동으로 시작하고, 부팅 알림 서비스(`BootNotificationService`)가 있다 | 다시 시작한 PC가 켜지면 요청한 휴대폰에 "다시 켜졌습니다"를 보낸다 |
| 기록 | PC 알림 센터, 명령 기록 보관(`retention.commandLogDays`) | 명령마다 "원격 명령" 항목을 남긴다 |

## 3. 명령 목록 (제안)

| 명령 | 실행 | 위험 | 비고 |
|---|---|---|---|
| **잠그기** | 트레이 `LockWorkStation` | 사용자 세션 | 바로 실행. 로그인한 사용자가 없으면 이미 잠긴 것으로 본다 |
| **화면 끄기** | 트레이 `SC_MONITORPOWER` | 사용자 세션 | 마우스·키보드를 움직이면 다시 켜진다 |
| **음소거 / 소리 크게·작게** | 트레이 가상 키(`VK_VOLUME_*`) | 사용자 세션 | 누를 때마다 한 단계 |
| **미디어 재생·일시정지 / 다음 / 이전** | 트레이 가상 키(`VK_MEDIA_*`) | 사용자 세션 | 지금 재생 중인 앱에 간다(브라우저·Spotify 등) |
| **다시 시작** | Agent `shutdown /r /t 60` | 시스템 | PC에 60초 카운트다운 토스트와 [취소](`shutdown /a`)를 띄운다. 휴대폰에도 [취소]가 있다. 켜지면 알린다 |
| **절전** | Agent `SetSuspendState` | 시스템 | 연결이 끊긴다. 깨우기(Wake-on-LAN)는 §4.6 선택 기능 |
| **사용자 정의 명령**(선택) | 트레이가 사용자 권한으로 실행 | 사용자 세션 | PC에서 이름·프로그램·인자를 등록한 것만 고른다. 휴대폰은 인자를 바꿀 수 없다(KDE Connect "명령 실행"과 같은 모델) |

**넣지 않는 것**
- **전원 끄기**: 요청대로 뺀다(다시 켤 길이 없다).
- **로그오프**: 저장하지 않은 작업을 잃는다. 잠그기로 충분하다.
- **임의 명령·셸, 원격 데스크톱, 마우스·키보드 원격 조작**: 프로젝트 원칙상 범위 밖이다.
- **프로세스 끝내기**: 실수 비용이 커서 이번에는 넣지 않는다(읽기 전용 프로세스 목록은 이미 있다).

## 4. 제안

### 4.1 허용 (PC에서)

- **기본값**: 모든 명령이 **꺼져 있다**.
- **켜는 곳**: PC 트레이 설정 › 휴대폰 탭의 "원격 명령"에서 명령마다 체크한다.
  - 다시 시작·절전은 시스템을 바꾸므로 관리자 승인(UAC)을 거쳐 Agent 설정 `mobile.commands`에 쓴다.
  - 사용자 세션 명령은 이 Windows 사용자의 트레이 설정에 둔다.
- **누가 요청하나**: 그룹의 기기(연결한 휴대폰과 PC) 모두. 설정에서 명령마다 "휴대폰만"으로 좁힐 수 있다.
- **목록 알리기**: PC는 `GET /api/v1/commands`로 켠 명령만 알려 준다. 앱과 다른 PC는 그것만 버튼으로 보인다.

### 4.2 요청 보호

- **봉인**: 요청 본문은 클립보드 봉투(M-62) `{schema, id, nonce, data}`이고, `data`는 그 기기와 PC의 합의 키로 봉인한 `{schema, command, ts}`다.
  - Bearer 토큰을 본 Cloudflare 엣지도 합의 키가 없으니 명령을 만들 수 없다.
- **재전송 막기**: `id`는 한 번만 받는다(10분 기억). `ts`가 PC 시계와 2분 넘게 다르면 거절한다. 엣지가 지난 요청을 다시 보내도 실행되지 않는다.
- **횟수 제한**: 기기마다 1분에 10번까지.
- **시스템 명령 확인**:
  - 휴대폰은 확인 대화상자를 띄우고, Android 잠금 해제(지문·PIN)를 다시 요구한다(결정 Q2).
  - PC에서는 60초 카운트다운 동안 누구든 [취소]할 수 있다.

### 4.3 실행

- **사용자 세션 명령**: Agent가 브리지로 트레이에 `command.run {name}`을 보내고, 트레이가 실행한 뒤 답한다(클립보드 `clip.done`과 같은 방식). 트레이가 없으면 409 `no_user_session`.
- **다시 시작**:
  1. Agent가 `shutdown /r /t 60 /c "<기기>에서 다시 시작을 요청했습니다"`를 실행한다. Windows가 띄우는 경고에 더해, 트레이가 [취소] 버튼이 있는 토스트를 띄운다.
  2. 휴대폰에는 "60초 뒤 다시 시작합니다 [취소]"가 뜬다. 취소는 `POST /api/v1/commands/cancel`(같은 봉인 방식)이다.
  3. 켜지면 요청한 기기에 "다시 켜졌습니다" 푸시를 보낸다(요청을 Agent 상태에 남겨 둔다).
- **절전**: 3초 뒤(답을 먼저 보낸 뒤) `SetSuspendState(false, false, false)`.
- **답**: 200 `{schema, ok, state}`. `state`는 `done`·`scheduled`(다시 시작 카운트다운)·`cancelled`. 오류는 `not_allowed`(꺼진 명령)·`no_user_session`·`busy`·`replayed`.

### 4.4 휴대폰 앱

- **어디서**: PC 화면에 "원격 명령" 칸을 두고, PC가 켠 명령만 버튼으로 보인다.
  - 미디어는 [⏮][⏯][⏭]과 [🔇][−][+] 한 줄씩.
  - 잠그기, 화면 끄기, 다시 시작, 절전은 아이콘 버튼으로 둔다.
- **결과**: 실행하면 짧은 알림이나 스낵바로 결과를 보인다. 다시 시작은 진행 알림에 [취소]를 둔다.
- **PC 카드 메뉴**에도 "잠그기"를 둔다(가장 자주 쓸 것).
- **빠른 설정 타일**: 마지막 PC 잠그기(선택, 결정 Q1).

### 4.5 다른 PC에서

- Homebase 창 기기 목록에서 PC를 오른쪽 클릭하면 "원격 명령 ▸"이 있다. 상세 화면에도 같은 버튼을 둔다.
- 보내는 PC의 Agent가 상대 PC에 같은 봉인 요청을 보낸다(`HubLinkService`, 키는 `KeyForPcAsync`).

### 4.6 (선택) 깨우기 — Wake-on-LAN

- 절전한 PC를 다시 켠다. 같은 LAN의 휴대폰이나 다른 PC가 매직 패킷을 보낸다.
  - PC는 자기 유선 랜카드 MAC 주소를 `presence`에 싣는다.
  - 깨우는 기기는 같은 서브넷 브로드캐스트로 UDP 9번 포트에 보낸다.
- **한계**: BIOS·랜카드에서 WoL을 켜야 한다. Wi-Fi만 쓰는 노트북은 대부분 안 된다. 밖에서(LTE) 깨우려면 같은 집의 다른 PC가 대신 보내야 한다.
- 절전을 쓸모 있게 만드는 짝이라 별도 단계로 둔다.

### 4.7 기록

- PC 알림 센터에 "원격 명령" 항목을 남긴다: 기기, 명령, 결과, 취소 여부. 왼쪽 필터에 "원격 명령" 칸을 둔다.
- 휴대폰 앱 알림 센터에도 "보낸 명령"을 남긴다.

## 6. 대가와 위험

- **토큰을 넘어선 공격면이 생긴다**: 지금까지 휴대폰이 PC를 바꾸는 일은 클립보드와 파일뿐이었다. 명령이 늘면 휴대폰을 잃었을 때의 피해가 커진다.
  - 그래서 기본은 꺼짐이고 명령마다 켠다.
  - 시스템 명령은 휴대폰 잠금 해제를 다시 요구하고, PC에서 취소할 수 있다.
  - 휴대폰을 잃으면 지금처럼 PC에서 연결을 해제한다.
- **다시 시작**: 저장하지 않은 작업을 잃을 수 있다. 60초 카운트다운과 Windows 경고로 줄인다. PC 앞에 사람이 있으면 취소할 수 있다.
- **절전**: 깨울 방법이 없으면 사람이 PC에 가야 한다. 버튼 옆에 "깨우려면 PC 앞에서" 또는 WoL이 있을 때 [깨우기]를 보인다.
- **미디어 키**: 지금 포커스가 있는 앱이나 시스템 미디어 세션에 간다. 어느 앱이 받을지는 Windows가 정한다.

## 7. 검증 계획

- **단위**: 봉인 요청 열기, 잘못된 키, 재전송(같은 id), 오래된 `ts`, 꺼진 명령 `not_allowed`, 횟수 제한, 트레이 없을 때, 다시 시작 예약과 취소 상태, 기록.
- **트레이 실제 실행**: 잠그기, 화면 끄기, 볼륨·미디어 키. 다시 시작은 테스트용으로 `/t 600`을 건 뒤 `shutdown /a`로 취소되는지 본다.
- **실기**: 휴대폰에서 LAN·Tailscale·Cloudflare 경로마다 잠그기. 다시 시작 → 켜짐 알림. PC → PC 잠그기.

## 8. 결정이 필요한 것

1. **첫 PR의 명령**: 잠그기·화면 끄기·미디어·볼륨·다시 시작·절전 — 권장. 사용자 정의 명령과 깨우기는 다음 PR로.
2. **시스템 명령 확인**: 휴대폰 확인 대화상자 + 잠금 해제 + PC 60초 카운트다운·취소 — 권장. 대안은 잠금 해제 없이 확인 대화상자만.
3. **기본값**: 모든 명령을 꺼 두고 PC 설정에서 켠다(다시 시작·절전은 관리자 승인) — 권장. 대안은 잠그기·미디어만 기본으로 켜 두기.
4. **다른 PC에서 요청**: 그룹 PC도 허용 — 권장. 대안은 휴대폰만.
