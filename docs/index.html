✦ HOMEBASE

당신의 PC를
주머니 속으로

집·회사·노트북 Windows PC를 휴대폰에서 실시간으로 지켜보고, 경보와 알림을 종단 암호화 푸시로 받습니다. 인터넷에 포트를 열지 않습니다.

기능

📱

휴대폰에서 실시간 모니터링

여러 PC를 등록해 두고 골라 들어가면 열린 창, 창(프로세스)별 CPU·RAM·I/O·네트워크, 지금 작업 중인 문서·코드 프로젝트·브라우저 탭이 1초마다 갱신됩니다. 보지 않을 때는 수집하지 않습니다.

🔗

기기끼리 서로 보기

휴대폰과 PC가 서로의 상태를 봅니다 — 휴대폰은 배터리·네트워크, PC는 CPU·메모리·가동 시간. PC끼리는 링크나 24단어 연결 코드로 잇습니다.

🔔

종단 암호화 푸시

감시 경보, 이벤트 로그, 부팅, Windows 알림을 UnifiedPush로 휴대폰에 보냅니다. PC가 휴대폰 키로 암호화(RFC 8291)하므로 중계 서버는 암호문만 봅니다. 받을 종류는 앱에서 고릅니다.

🔁

알림 주고받기

PC의 Windows 알림이 연결된 PC로, 원하면 휴대폰 알림이 PC로 갑니다. 한 단계만 전달하고 되돌아오지 않으며, 인증기·비밀번호 관리자 앱은 기본으로 뺍니다.

🗂️

알림 센터

휴대폰 앱과 PC 트레이 모두 받은 알림을 날짜별로 30일간 보관합니다. 알림 창에서 지운 알림도 다시 볼 수 있습니다.

🖥️

상태 확인과 감시

CPU·RAM·디스크·온도와 가동 시간, 프로세스·서비스·HTTP·포트 감시, Windows 오류 이벤트 감시. 로컬 AI(Ollama)를 켜면 오류의 뜻과 확인할 점을 덧붙입니다.

🛡️

포트를 열지 않는 연결

QR 한 장으로 연결합니다. 같은 Wi-Fi(TLS, 인증서 고정), Tailscale, Cloudflare Tunnel 중 지금 되는 경로를 앱이 알아서 고릅니다.

🔒

프라이버시 우선

비밀번호·OTP·토큰은 마스킹하고 민감한 앱은 차단합니다. 광고·분석·사용 기록 수집이 없고, 앱은 연결한 PC와 직접 통신합니다.

설치

모두 최신 릴리스에 있습니다. 푸시 알림을 받으려면 휴대폰에 UnifiedPush 배포자 앱 ntfy(무료, 계정 없음)가 필요합니다.

Homebase-Setup.exe

Telegram 명령어

Telegram 봇은 전환 기간 동안 대체 채널로 남아 있습니다. 푸시를 등록한 휴대폰이 없거나 전송이 실패한 경보만 Telegram으로 갑니다.

명령어설명
/status전체 PC 상태 요약
/disk드라이브별 디스크 사용량
/process감시 중인 프로세스 상태
/servicesWindows 서비스 상태
/events최근 Windows 이벤트 로그
/alerts최근 알림 이력
/mute 1h알림 음소거
/help모든 명령어 보기
