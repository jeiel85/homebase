02AI 코딩 세션

Claude Code가 기다리면,
휴대폰이 알려 줍니다.

작업 탭에서 Claude Code·Codex 세션마다 작업 중인지, 입력을 기다리는지, 쉬는 중인지와 모델·컨텍스트 사용량·마지막 도구를 봅니다. 기다리는 세션이 맨 위로 올라옵니다.

  1. 자리를 비우면

    1분 동안 키보드·마우스 입력이 없으면 자리를 비운 것으로 봅니다.

  2. 휴대폰이 울립니다

    Claude Code가 승인이나 답을 기다릴 때, Claude Code·Codex가 1분 넘게 걸린 작업을 마쳤을 때 알림이 옵니다.

  3. 알림에서 허용·거부

    권한 요청은 실행할 명령이나 고칠 파일과 함께 옵니다. 누르려면 휴대폰 잠금을 풀어야 합니다.

  4. 아니면 PC에서 그대로

    PC로 돌아오거나 10분 동안 답이 없으면 Claude Code가 평소처럼 PC에서 묻습니다.

승인 기능은 기본으로 꺼져 있습니다. PC의 설정 → 휴대폰 → ‘AI 세션 승인’을 켜면 Claude Code 설정에 훅 하나만 더하고, 끄면 그 훅만 지웁니다. 세션 화면에는 프롬프트와 답변이 실리지 않습니다.

03기기 그룹

한 번 연결하면,
그룹 전체가 연결됩니다.

휴대폰을 PC 한 대에 연결하거나 PC 두 대를 이으면, 몇 분 안에 그룹의 모든 PC와 휴대폰이 서로 연결됩니다. 기기마다 하나씩 짝지어 줄 필요가 없습니다.

  • PC끼리는 링크나 24단어 연결 코드로. 이미 연결된 기기들이 일회용 코드로 새 기기를 서로 소개합니다.
  • 빼면 그룹 전체에서. 한 PC에서 해제하면 모든 PC에서 끊기고, 그때 꺼져 있던 PC도 켜지면 따라갑니다.
  • 주소가 바뀌어도 다시 이어집니다. 한 PC의 터널 주소나 LAN 주소가 바뀌면, 그 PC가 닿는 쪽에 새 주소를 알려 저절로 다시 연결합니다.
  • 휴대폰에서 PC를 조작합니다. 잠그기·화면 끄기·음악 재생·볼륨은 바로, 다시 시작·절전은 PC에서 켠 경우에만 휴대폰 잠금 해제 뒤 실행됩니다(다시 시작은 PC에 60초 카운트다운과 취소). 절전한 PC는 같은 Wi-Fi에서 깨울 수 있습니다.
  • 사진·파일을 서로. 휴대폰 공유 메뉴에서 Homebase를 고르면 공유 센터가 열려, PC 여러 대나 다른 휴대폰을 골라 한 번에 보냅니다. PC에서는 트레이의 "파일 보내기", 탐색기의 "보내기 › Homebase", Homebase 창에 끌어다 놓기로 보냅니다(폴더는 zip으로). PC는 다운로드 폴더에, 휴대폰은 알림이 오면 바로 받아 갤러리나 다운로드 폴더에 저장합니다. 큰 파일도 끊긴 곳부터 이어 갑니다.
  • 복사한 텍스트를 서로 보냅니다. PC 트레이의 "클립보드 보내기", 휴대폰의 공유 메뉴나 빠른 설정 타일로 보내면 받는 기기의 클립보드에 바로 들어갑니다. 내용은 그 기기만 여는 키로 암호화됩니다.
  1. 1작업실 PC의 QR을 찍습니다
  2. 2그룹이 새 휴대폰을 소개합니다
  3. 3모든 PC가 연결됐습니다

종단 암호화

PC가 휴대폰의 키로 암호화합니다(RFC 8291). 푸시를 중계하는 서버는 암호문만 봅니다. 받을 종류는 휴대폰에서 고르고, PC가 보내기 전에 거릅니다.

알림 주고받기

PC의 Windows 알림은 휴대폰과 다른 PC로, 원하면 휴대폰 알림은 PC로 갑니다. 한 단계만 건너고 되돌아오지 않으며, 비밀번호 관리자·인증 앱은 항상 뺍니다.

알림 센터

휴대폰 앱과 PC 창 모두 받은 알림을 30일 동안 날짜별로 남깁니다. 알림창에서 지운 알림도 다시 볼 수 있고, 같은 출처는 한 카드로 묶입니다.
