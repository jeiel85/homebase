Homebase 휴대폰 연결

PC의 열린 창과 프로세스별 CPU·RAM·네트워크를 휴대폰에서 실시간으로 봅니다.

연결할 PC:

  1. Homebase 앱 설치 (Android)

    Play 스토어가 아니라 GitHub 릴리스에서 직접 받는 앱입니다.

    앱 받기 (APK)

  2. 설치 허용

    다운로드한 Homebase-Mobile.apk를 알림이나 '파일'에서 엽니다. 처음이면 Android가 막습니다.

    • "보안상의 이유로 … 설치할 수 없습니다" → 설정 → 이 출처 허용을 켜고 뒤로 돌아옵니다.
    • 설치를 누릅니다. 이후 업데이트는 앱이 알려 줍니다.

  3. 앱에서 열어 연결

    설치가 끝나면 이 페이지로 돌아와 아래 버튼을 누르세요. 앱이 이 PC의 연결 정보를 받아 연결 확인을 묻습니다.

    앱에서 열기

    PC 트레이 아이콘 메뉴 → 설정… → 휴대폰 탭(영어 Windows: Settings… → Phone)에 표시된 QR을 휴대폰 카메라나 앱의 기기 추가로 스캔하세요.

이 기기는 Android가 아닌 것 같습니다. Homebase 앱은 Android 전용입니다.

QR에 담긴 연결 코드는 주소의 # 뒤에만 있어 이 페이지를 연 브라우저 밖으로 전송되지 않습니다. 코드는 5분 동안 한 번만 쓸 수 있습니다. 만료되었으면 PC 창에서 NEW CODE를 누르고 다시 스캔하세요. 자세히
